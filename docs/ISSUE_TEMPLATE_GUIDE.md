# Issue テンプレートの使い方

新しい Issue を作成するとき、テンプレートを選ぶと **入力欄付きのフォーム** が表示されます。
各項目を見ながら記入して Issue を作成できます。

## テンプレートの開き方

1. リポジトリの **Issues** タブを開く
2. **New issue** をクリック
3. 使いたいテンプレートを選択する

| テンプレート | いつ使うか |
|-------------|-----------|
| **大タスク** | 新しいプロジェクト・案件を始めるとき |
| **中タスク** | 大タスクを成果物単位に分解するとき |
| **小タスク** | 実際の作業単位を登録するとき |

---

## 大タスクテンプレート

### 記入する項目

| # | 項目 | 記入のコツ |
|---|------|-----------|
| ① | 背景・目的 | 「なぜ今やるのか」を書く |
| ② | 届け先 | 誰に届けるか。名前・役割を具体的に |
| ③ | 成功状態 | 相手がどうなれば成功か（自分の作業完了ではない） |
| ④ | 成果物 | `- [ ]` 形式のチェックリスト |
| ⑤ | 中タスク一覧 | 作成後に Sub-Issue で分解 |
| ⑥ | 振り返り | 完了後に記入（作成時は空欄でOK） |

### 記入例

**① 背景・目的**
```
AI研修第6回で「時間管理の仕組み化」が課題として挙がった。
現状は振り返りが属人化しており、仕組みが必要。
```

**③ 成功状態**
```
上司が「この仕組みで進めてよい」と判断できる。
自分が次のタスクでも同じ手順で再現できる。
```

### 作成後の作業

1. Projects で `タスク階層 = 大タスク`・`Status = 未着手` を設定
2. 中タスクを **Sub-Issue** として作成（中タスクテンプレートを使用）

---

## 中タスクテンプレート

### 作成手順

1. **親の大タスク Issue** を開く
2. **Create sub-issue** をクリック
3. 「中タスク」テンプレートを選択して記入

### 記入する項目

| 項目 | 記入のコツ |
|------|-----------|
| 成果物の定義 | 1文で「何を作るか」を書く（これだけ記入すればOK） |

### 作成後の作業

1. Projects で `タスク階層 = 中タスク`・`Status = 未着手` を設定
2. 必要に応じて小タスクを **Sub-Issue** として作成

---

## 小タスクテンプレート

### 作成手順

1. **親の中タスク Issue** を開く
2. **Create sub-issue** をクリック
3. 「小タスク」テンプレートを選択して記入

### 記入する項目

| 項目 | 選択肢 |
|------|--------|
| 作業内容 | 自由記述（80点で見せる前提） |
| インパクト | 大 / 中 / 小 |
| 時間負荷 | すぐ終わる / 普通 / 重い |
| 気軽さ | 楽 / 普通 / 気重 |
| 予想時間 | 15分 / 30分 / 1時間 / 3時間 / それ以上 |

### 作業の進め方

| タイミング | Projects で設定すること |
|-----------|----------------------|
| 作業開始時 | Status → 着手中 |
| 作業完了時 | 実時間（分）を記入 → Status → 完了 |
| 予想と差がある場合 | 予想との差異理由を記入 |

---

## タスク階層のイメージ

```
大タスク #2
├── 中タスク #5（Sub-Issue）
│   ├── 小タスク #8（Sub-Issue）
│   └── 小タスク #9（Sub-Issue）
└── 中タスク #6（Sub-Issue）
    └── 小タスク #10（Sub-Issue）
```
