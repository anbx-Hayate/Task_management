# GitHub Projects セットアップ手順

このドキュメントは [anbx-Hayate/Task_management](https://github.com/anbx-Hayate/Task_management) の Projects 初期設定手順です。

## 自動セットアップ（推奨）

GitHub CLI (`gh`) がインストール・認証済みの場合、`scripts/` 内の GraphQL ファイルを使って自動設定できます。

**すでに以下は設定済みです（2026-06-05 実施）：**

| 項目 | 状態 | URL |
|------|------|-----|
| プロジェクト | 作成済み | https://github.com/users/anbx-Hayate/projects/3 |
| ラベル | 作成済み | 大タスク / 中タスク / 小タスク / 振り返り待ち |
| カスタムフィールド | 作成済み | 下記一覧参照 |
| 初期大タスク Issue | 作成済み | https://github.com/anbx-Hayate/Task_management/issues/2 |

再セットアップが必要な場合は `scripts/setup_project.py`（Python 要）または `scripts/*.graphql` を参照してください。

---

## 1. プロジェクト作成

1. リポジトリの **Projects** タブを開く
2. **New project** → テンプレート **Board** を選択
3. プロジェクト名：`タスク管理ボード`
4. データソースにこのリポジトリの Issues を追加

## 2. Status（進捗）の設定

**Settings → Fields → Status** で以下に変更する。

| 選択肢 | 用途 |
|--------|------|
| 未着手 | まだ作業を開始していない |
| 着手中 | 現在作業中 |
| 完了 | 作業完了 |
| 保留 | 一時停止（理由を Issue コメントに記載） |

## 3. カスタムフィールド一覧

**Settings → Fields → New field** から以下を作成する。

### 必須フィールド

| フィールド名 | 型 | 選択肢 | 用途 |
|--------------|-----|--------|------|
| タスク階層 | Single select | 大タスク / 中タスク / 小タスク | 階層別フィルタ・ビュー分け |
| インパクト | Single select | 大 / 中 / 小 | 優先順位判断（重要度） |
| 時間負荷 | Single select | すぐ終わる / 普通 / 重い | 作業の重さ。午前割り当ての判断材料 |
| 気軽さ | Single select | 楽 / 普通 / 気重 | 心理的ハードル。午後の機械的作業候補 |
| 予想時間 | Single select | 15分 / 30分 / 1時間 / 3時間 / それ以上 | 作業前の見積もり |
| 実時間（分） | Number | （数値入力） | 実際にかかった時間（分単位） |
| 予想との差異理由 | Single select | 差異なし / 調査時間が増加 / 手戻り発生 / レビュー対応発生 / 想定以上に難しかった / その他 | 予実差の原因記録 |
| 差異理由（補足） | Text | （自由記述） | 詳細説明が必要な場合 |

### 推奨フィールド

| フィールド名 | 型 | 選択肢 | 用途 |
|--------------|-----|--------|------|
| 届け先 | Single select | 上司 / クライアント / チーム / 自分 / その他 | 成果物の宛先 |
| 完了日 | Date | （日付） | 実績把握 |
| 振り返り済み | Single select | 未実施 / 実施済み | 大タスクの振り返り漏れ防止 |

## 4. 推奨ビュー

| ビュー名 | レイアウト | 設定 |
|----------|------------|------|
| 全体ボード | Board | グループ：Status |
| 大タスク一覧 | Table | フィルタ：タスク階層 = 大タスク |
| 今週の作業 | Board | フィルタ：タスク階層 = 小タスク、Status ≠ 完了 |
| 工数・振り返り | Table | 表示列：予想時間・実時間（分）・予想との差異理由・完了日 |

## 5. ラベル作成

**Issues → Labels** で以下を作成する。

| ラベル | 色（推奨） | 用途 |
|--------|------------|------|
| 大タスク | `#7057ff`（紫） | 階層識別 |
| 中タスク | `#1d76db`（青） | 階層識別 |
| 小タスク | `#0e8a16`（緑） | 階層識別 |
| 振り返り待ち | `#fbca04`（黄） | 振り返り未記入の大タスク |

## 6. フィールドと階層の対応

| フィールド | 大タスク | 中タスク | 小タスク |
|------------|:--------:|:--------:|:--------:|
| Status | ○ | ○ | ○ |
| タスク階層 | ○ | ○ | ○ |
| インパクト | ○ | ○ | ○（必須） |
| 時間負荷 | △ | ○ | ○（必須） |
| 気軽さ | △ | ○ | ○（必須） |
| 予想時間 | × | △ | ○（必須） |
| 実時間（分） | × | × | ○（必須） |
| 予想との差異理由 | × | × | ○（完了時） |
| 届け先 | ○ | △ | × |
| 振り返り済み | ○（完了時） | × | × |

○＝必須、△＝任意、×＝不要
